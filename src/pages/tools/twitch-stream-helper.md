Twitch Stream Helperは、Twitchの配信設定とXの告知準備をまとめて行えるChrome拡張機能です。
重いクリエイターダッシュボードを行き来せず、配信前のルーティンを短時間で整えられます。

**v1.1.0を公開しました。** 以下のコメント自動投稿・固定は現在のChrome Web Store版で利用できます。

### ⚡ 主な機能

1. **タイトル・カテゴリ・タグをまとめて更新**
   * カテゴリごとにタグの組み合わせを保存し、タイトルと一緒に適用できます。
   * 関連する変更を1回のAPI通信にまとめ、短時間の連続更新によるエラーを抑えます。
2. **タイトルテンプレートとリアルタイムプレビュー**
   * カテゴリ名、チャンネル名、タグ、日付などを変数として挿入できます。
   * 展開後の文字列と140文字の上限を、Twitchへ送る前に確認できます。
3. **分かりやすい反映状態**
   * 現在Twitchに設定されているタイトルを常時表示します。
   * 編集中、反映中、反映済み、失敗を区別して表示するため、更新結果を見失いません。
4. **X告知文の作成**
   * 配信タイトルやURLを自動挿入し、Xの投稿画面を開きます。
   * 配信URLを付けない設定や、タイトル・URLを好きな位置に置くテンプレートにも対応しています。
5. **配信ごとのコメント自動投稿・任意の固定（v1.1.0）**
   * 配信ルールや参加案内などの保存した文章を、自分のアカウントで自分のライブチャットへ配信ごとに1回投稿できます。自動投稿は初期状態ではオフです。
   * 共通コメントとカテゴリ別コメントを各500文字以内で保存できます。固定は任意で、配信終了まで・30分・10分から選べます。

## 💬 コメント自動投稿の使い方（v1.1.0）

1. Twitchにログインし、「固定コメント」に共通の文章を入力します。
2. 必要に応じて、カテゴリ履歴からカテゴリを選び、カテゴリ別の文章を保存します。空欄のカテゴリでは共通コメントを使います。
3. 「コメントを固定する」のオン・オフと固定時間を選びます。
4. 「配信開始時に1回だけ自動投稿」を有効にし、「設定を保存」を押します。保存にはログインが必要です。

ブラウザが起動中でPCがスリープしていない間、約1分ごとに配信状態を確認します。ポップアップは閉じていても構いません。有効化時やブラウザの再起動時にすでに配信中でも、その配信が未投稿なら次の確認時に投稿します。ブラウザ終了中・スリープ中は配信開始を検知できません。

投稿時にTwitchから取得したカテゴリで文章を選びます。配信途中のカテゴリ変更では再投稿しません。コメントでは、下記のタイトル・X告知用テンプレート変数は展開されません。

### 手動投稿・再試行と固定の動作

* 「今すぐ投稿・再試行」は配信中に使用できます。投稿済みの配信には再投稿せず、固定だけ失敗していた場合は元のコメントと固定時間で固定のみを再試行します。
* 書き込みに失敗しても自動再送しません。レート制限が表示されたら、少なくとも1分、Twitchがそれより遅い再試行時刻を指定した場合はその時刻まで待ち、手動で再試行してください。
* 送信結果が不明な場合は、重複を避けるため再送を抑止します。Twitchのチャットを確認し、届いていなければTwitch上で手動投稿してください。
* 固定すると既存の固定コメントを置き換えます。期限切れや手動解除後に自動で再固定・再投稿することはありません。
* 共有チャット中は、投稿したコメントが共有先のチャンネルにも表示されます。

重複投稿の防止には、このブラウザ内の投稿記録を使います。記録はアカウントごとに直近100配信分を保持します。データ削除・再インストール後や、複数のPC・ブラウザで同時に実行した場合の重複は防げません。

### ログインと停止方法

v1.1.0では通常のログイン時に、配信情報の管理に加え、チャット投稿とチャットメッセージ管理の権限をまとめて要求します。後者はコメントの固定に使用します。自動投稿や固定を使わない場合も、ログイン時の要求は同じです。旧バージョンの権限でログイン済みの場合は、案内に従って一度再ログインしてください。設定と投稿記録は引き継がれます。

自動投稿を止めるには、チェックを外して設定を保存するか、ログアウトします。ログアウトすると自動投稿はオフになり、定期確認を停止しますが、コメント設定や投稿記録は残ります。アカウントを切り替えた場合はコメントを確認して設定を保存し直してください。認証の有効期限が切れた場合も再ログインが必要です。詳しくは[プライバシーポリシー](/privacy/twitch-stream-helper/#japanese)をご覧ください。

## ✨ テンプレートで使える変数

配信タイトルとX告知文で使用できます。コメント自動投稿の文章には適用されません。

| 変数 | 内容 |
| --- | --- |
| `{category}` | 選択中のカテゴリ名 |
| `{category_hashtag}` | カテゴリ名から生成したハッシュタグ |
| `{channel}` | Twitchチャンネル名 |
| `{stream_url}` | Twitch配信URL |
| `{tags}` | 選択中のタグ |
| `{tag_hashtags}` | タグをハッシュタグ化した文字列 |
| `{date}` / `{time}` | 現地の日付・時刻 |
| `{title}` | 現在の配信タイトル（X告知文のみ） |

例：`【{category}】{date} 配信スタート！ {stream_url}`

## 🛠️ 使い方とワークフロー

1. 拡張機能をインストールし、Twitchアカウントでログインします。
2. ポップアップでカテゴリとタグを選び、タイトルテンプレートを入力します。
3. プレビューを確認し、入力欄からフォーカスを外すかEnterを押して反映します。
4. 必要に応じてX告知文を編集し、投稿画面を開きます。
5. v1.1.0では、上記の手順でコメント自動投稿・固定を設定できます。
