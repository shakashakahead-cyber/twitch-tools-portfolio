# Ichi Browser プライバシーポリシー

制定・更新日：2026年9月11日 / 対象：0.1.0-alpha32 以降の先行公開版

提供者：暁左衛門（Akatsukizaemon）

## 端末内のデータ

ブックマーク、よく見るサイト、設定、保存を有効にした閲覧履歴、サイトの Cookie・Web ストレージ、許可した HTTPS サイトのマイク権限などを端末内で管理します。開発者のサーバーへの履歴の同期、利用者アカウント、独自の行動分析・広告用 SDK は実装していません。これらのデータを開発者に自動送信する機能はありません。

## 利用する機能に伴う通信

- 閲覧先・検索エンジンには、利用者が入力した URL、検索語、送信したフォームや添付ファイルなどが送られます。アクセス先は IP アドレスやブラウザ情報等を受け取ります。各サービスのポリシーが適用されます。
- GeckoView の安全な閲覧のための情報取得、uBlock Origin のフィルター更新、サイトアイコンの取得など、機能に必要な通信があります。これらは閲覧履歴を開発者へ送信する機能とは別です。配布元のサービス規約・ポリシーも適用されます。
- RSS ニュースは初期状態ではオフです。オンにすると登録した配信元へ直接問い合わせ、見出しやリンク等を取得します。プライベート中は表示・取得しません。
- 翻訳は対応する言語・端末で端末内処理を行います。通常モードで初回に許可した場合、言語データを取得します。本文を外部の翻訳サーバーへ送る実装ではありません。プライベート中は利用できません。
- 「アプリの更新を確認」を押すと、shakashakahead.com に公開版の情報を問い合わせます。閲覧履歴、端末の識別子、現在のアプリ版をリクエストに追加しません。接続先は IP アドレス等の通常の通信情報を受け取ります。自動確認・自動インストールは行いません。
- 紹介ページを開くと、この Web サイトで使用する Google Analytics・Google Fonts 等の通信が発生します。APK のダウンロードは GitHub Releases を使用します。ホスティング・配布サービスがアクセスログを処理する場合があります。

## カメラ・マイク・位置情報・ファイル

Web サイトの要求時に利用者へ確認します。通常モードで許可した HTTPS サイトのマイク権限は保存します。Android 側の権限がない場合は自動許可しません。カメラの許可、拒否、プライベート中の許可はページ移動や再読み込みで解除します。ファイルは Android の選択・保存画面を使用します。通常モードの添付には一時コピーを使用し、セッション終了時と次回起動時に削除します。プライベート中の添付は無効です。

## プライベートモード

通常の閲覧とはセッションを分離し、通常の履歴へ保存しません。ネットワーク上の匿名性を保証するものではなく、閲覧先や通信事業者には通信が発生します。エンジン内部を含むあらゆる残留データの不存在を保証するものではありません。

## 削除・変更

「設定」→「閲覧データを削除」で対象データを選択して削除できます。保存したサイト権限は「メニュー」→「サイト設定」のリセットでも解除できます。Cookie・サイトデータの削除でも解除します。アプリをアンインストールするとアプリ内データが削除されますが、利用者が共有ストレージへ保存したダウンロード済みファイルは別途削除が必要です。
