# 🔰 Getting Started

Hello, I'm Akatsukizaemon.
At this lab, we develop and release tools for Twitch streamers with the theme of **"Solving streamers' 'hassles' with technology"**.

If you're wondering "Which one should I use?", here are some recommendations based on your needs.

## 🔍 What is your problem?

### 😫 "Reviewing stream archives is hard! I just want to clip the funny moments."
For you...
👉 **[Clip Extractor](/en/tools/clip-extractor/)**

- **What does it do?**: AI automatically detects "laughter" and "cheers" in the video and lists only the exciting scenes.
- **Why recommend?**: Check a 6-hour stream in minutes. It's a desktop app (Windows).

---

### 😫 "Changing tags and titles every stream is a hassle."
For you...
👉 **[Twitch Stream Helper](/en/tools/twitch-stream-helper/)**

- **What does it do?**: Save frequently used tag combinations as presets and post X (Twitter) announcements with one click when starting a stream.
- **Why recommend?**: It's a Chrome extension, so just install it and you're ready. Speed up your stream setup.

---

### 😫 "I miss comments while gaming / I'm bored with standard TTS."
For you...
👉 **[Comment Reader for Twitch (VOICEVOX)](/en/tools/voicevox-comment-reader/)**

- **What does it do?**: Reads viewer comments with high-quality voices like Zundamon and Shikoku Metan.
- **Why recommend?**: No complex setup required. Just install the Chrome extension and open the Twitch dashboard.

## 📊 Tool Comparison

| Tool Name | Type | Purpose | Platform |
