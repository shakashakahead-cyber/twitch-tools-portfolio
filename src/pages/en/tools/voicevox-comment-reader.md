## 🚀 Don't Miss Chat with "Great Voices"

**"Missed a comment because I was focused on the game..."**
**"Bored of the robotic default TTS voices..."**

For streamers like you, we recommend **Twitch Comment Reader (VOICEVOX)**.
Popular VOICEVOX characters like Zundamon and Shikoku Metan will read your chat aloud with emotion.

### 🌟 Main Features

1.  **High-Quality AI TTS**
    *   Integration with VOICEVOX for natural and easy-to-hear comment reading.
2.  **No Configuration Needed**
    *   Just open your Twitch Creator Dashboard and it connects automatically. No OBS settings changes required.

---

## 📖 Setup Guide

Start in just 3 steps.

1.  Install and launch **VOICEVOX** from the [Official Site](https://voicevox.hiroshiba.jp/).
2.  Install this **Chrome Extension**.
3.  Open Twitch **Creator Dashboard (Stream Manager)**.
    *   That's it! The extension launches and connects automatically.

> [!TIP]
> If reading doesn't start, check if VOICEVOX is running and try reloading the dashboard.

---

## ❓ FAQ

**Q. Is it free?**
A. Yes, the extension itself is completely free. (Please follow VOICEVOX terms of service regarding their software usage).

**Q. How to capture audio in OBS?**
A. This extension plays sound from the browser (e.g., Chrome) by default. Use "Desktop Audio" in OBS to capture the browser sound.

**Q. Some comments are skipped (e.g., Bots)**
A. You can configure filters in the settings to skip bots or specific commands (comments starting with `!`).
