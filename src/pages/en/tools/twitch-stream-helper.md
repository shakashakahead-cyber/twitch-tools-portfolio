## 🎮 Zero Hassle for Stream Prep

**"Tired of typing the same tags every time..."**
**"Forgot to change title and tags when switching games..."**

Twitch Stream Helper was developed to solve these streamer headaches.
Automate your pre-stream routine so you can focus on what matters: **Streaming**.

### ⚡ Main Features

1.  **Tag Presets (Loadouts)**
    *   Save combinations of tags for "FPS", "Just Chatting", "Retro Games", etc. Recalling them takes just one click.
2.  **Smart Stream Settings**
    *   Update stream title, category (game), and tags all at once. No need to wait for the slow dashboard to load.
3.  **X (Twitter) Integration**
    *   Template your "Going Live!" posts. Automatically embed stream title and URL for smooth announcements.

---

## 🛠️ Usage & Workflow

Intuitive UI, easy for anyone to master.

1.  Install the extension and log in to Twitch.
2.  Open the popup and set your game category.
3.  Tags are automatically filled in.
4.  Optionally click the X post button to tweet out your stream.
