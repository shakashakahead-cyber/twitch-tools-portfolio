# 🔰 はじめての方へ

こんにちは、暁左衛門（あかつきざえもん）です。
当ラボでは、スマートフォンやTwitch配信で感じた不便を減らすツールを開発・公開しています。

「どれを使えばいいの？」と迷っている方のために、悩み別のおすすめツールをご紹介します。

## 🔍 あなたの悩みはどれですか？

### 😫「スマホのタブが増え続ける。ひとつのページに集中したい」
そんなあなたには…
👉 **[Ichi Browser（イチブラウザ）](/tools/ichi-browser/)**

- **何ができる？**: 別タブ指定のリンクも同じ画面で開く、Android向けの1タブブラウザです。広告ブロックや片手向けジェスチャー、対応言語の端末内翻訳も備えています。
- **おすすめポイント**: タブを閉じる作業を減らし、検索結果と読みたいページを「戻る・進む」でシンプルに行き来できます。現在はAndroid 14以降のarm64端末向け先行公開版です。

---

### 😫「配信アーカイブを見返すのが大変！面白いシーンだけ切り抜きたい」
そんなあなたには…
👉 **[クリップ抽出くん (Clip Extractor)](/tools/clip-extractor/)**

- **何ができる？**: 動画内の「笑い声」や「歓声」をAIが自動検知して、盛り上がったシーンだけをリストアップします。
- **おすすめポイント**: 6時間の配信も数分でチェック完了。デスクトップアプリ（Windows）です。

---

### 😫「配信のたびにタグやタイトルを変えるのが面倒くさい」
そんなあなたには…
👉 **[Twitch Stream Helper](/tools/twitch-stream-helper/)**

- **何ができる？**: タイトル・カテゴリ・タグ・X告知をまとめて管理し、配信中の自動コメントや任意の固定も設定できます。
- **おすすめポイント**: 配信後は平均・最大同接、コメント参加、Follow、Raidをローカルに記録し、グラフやCSVで振り返れます。

---

### 😫「ゲームに集中してコメントを見逃してしまう・棒読みちゃんに飽きた」
そんなあなたには…
👉 **[Comment Reader for Twitch (VOICEVOX)](/tools/voicevox-comment-reader/)**

- **何ができる？**: 視聴者からのコメントを、ずんだもんや四国めたんなどの「いい声」で読み上げます。
- **おすすめポイント**: 面倒な連携設定は不要。Chrome拡張機能を入れてTwitchダッシュボードを開くだけで動き出します。

## 📊 ツール比較表

| ツール名 | 形式 | 目的 | なにで動く？ |
| :--- | :--- | :--- | :--- |
| **Ichi Browser** | Androidアプリ | 1タブでのWeb閲覧・タブ整理の削減 | Android 14以降のarm64端末 |
| **クリップ抽出くん** | Windowsアプリ | 切り抜き作成・アーカイブ確認 | Windows PC |
| **Twitch Stream Helper** | Chrome拡張 | 配信設定・自動コメント・配信分析 | Chrome/Edge等のブラウザ |
| **Comment Reader** | Chrome拡張 | コメント読み上げ | Chrome/Edge + VOICEVOX |

全てのツールは**無料**でご利用いただけます。ぜひ気になったものから試してみてください！
